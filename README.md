# 2048 Doraemon 🎮🐱‍👓

[Play Now on GitHub Pages](https://kaloodinaz.github.io/2048-doraemon/)

2048 Doraemon is a fun and addictive tile-based puzzle game based on the original 2048, but with a delightful twist – every number tile features Doraemon-themed images and characters! It's a must-play for fans of both number games and the iconic blue robotic cat from the future.

## 🧩 How to Play

- Use your **arrow keys** (or swipe on mobile) to move the tiles.
- When two identical Doraemon tiles touch, they merge into one with a higher value.
- Keep merging tiles until you reach the final Doraemon tile.
- Try to get the highest score possible!

## 🚀 Features

- 🐱 Doraemon-themed tile graphics
- 🧠 Same addictive logic as the original 2048
- 🎨 Playable directly in your browser – no downloads needed
- 📱 Mobile-friendly design
